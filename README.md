\# 🤖 AI Resume Analyzer



An intelligent web application that analyzes resumes using Artificial Intelligence techniques. The system extracts skills from PDF resumes, calculates an ATS (Applicant Tracking System) score, recommends suitable job roles, identifies missing skills, and provides suggestions to improve the resume.



\---



\## 🚀 Features



\- 📄 Upload Resume (PDF)

\- 🔍 Extract Resume Text

\- 🧠 AI-Based Skill Extraction

\- 📊 ATS Score Calculation

\- 💼 Job Role Recommendation

\- ⚠️ Skill Gap Analysis

\- 💡 Resume Improvement Suggestions

\- 📱 Responsive User Interface

\## ⚙️ Installation



\### Clone the Repository



```bash

git clone https://github.com/Sagar142-ai/AI-Resume-Analyzer.git

```



\### Navigate to Project



```bash

cd AI-Resume-Analyzer

```



\### Create Virtual Environment (Optional)



```bash

python -m venv venv

```



\### Activate Virtual Environment



Windows



```bash

venv\\Scripts\\activate

```



Linux / Mac



```bash

source venv/bin/activate

```



\### Install Dependencies



```bash

pip install -r requirements.txt

```



\### Run the Application



```bash

python app.py

```



Open your browser and visit



```

```

\## 📋 How It Works



1\. User uploads a PDF resume.

2\. The application extracts text using \*\*PyPDF2\*\*.

3\. Skills are identified using keyword matching.

4\. ATS score is calculated based on resume content.

5\. Suitable job roles are recommended.

6\. Missing skills are highlighted.

7\. Suggestions are generated to improve the resume.



\---



\## 🎯 ATS Score Criteria



The ATS score is calculated using:



\- Technical Skills

\- Soft Skills

\- Resume Keywords

\- Education Details

\- Project Experience

\- Certifications

\- Formatting Quality
